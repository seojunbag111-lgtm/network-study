# 09-nat

## 1. 学んだこと (Learning)

- NAT
- Symmetric NAT
- ポートフォワーディング

## 2. 重要な概念 (Key Concepts)

### 1. NAT

- NATは、パケットがネットワークを通過する際にIPアドレスを変換する機能である。
- 一般的なルーターには、NAT機能が搭載されていることが多い。
- ホストがWebサーバーにアクセスする際に、ルーターがプライベートIPをインターネットで使用できるパブリックIPに変換する。
- NATでは、既存の変換情報に対応しない外部からのインバウンドパケットは、内部ホストへ転送されない場合が多い。
- NATの方式には、Cone NATやSymmetric NATなどがある。

### 2. Symmetric NAT

- Symmetric NATは、通信先ごとに異なる外部側のIPアドレスやポートのマッピングを生成する方式である。
- Symmetric NATは、IPだけではなく、ポート番号も変換する。
- IPアドレスやポート番号などの変換情報をNAT tableで管理し、戻ってきたパケットを適切な内部ホストへ転送するために使用する。

### 3. ポートフォワーディング

- ポートフォワーディングは、外部からのインバウンドパケットを内部ホストへ転送できるように、NATの変換規則を手動で設定する機能である。
- 使用する機器によっては、リモートIPに0.0.0.0、リモートポートに0を指定することで、接続元を限定しない設定をする場合がある。
- UPnPを利用することで、自動的にポートフォワーディングの設定が追加される場合もある。

## 3. 通信の流れ・仕組み (How It Works)

### NATによってIPアドレスが変換される仕組み

```text
PC
Source Address: 192.168.0.10
Destination Address: Googleサーバー
        ↓
      ルーター
        ↓ NAT
Source Address: 123.45.67.89  ← ルーターのパブリックIP
Destination Address: Googleサーバー
        ↓
      インターネット
```

- Webサーバーの立場ではルーターのパブリックIPからのリクエストのように見える。

### Symmetric NATがインバウンドパケットを処理する過程

```text
クライアントからパケットが生成される。
            ↓
送信元のIPアドレスとポート番号を外部側の情報に変換する。
            ↓      
NAT tableに変更に関する情報を追加する。
            ↓
NAT tableを確認し、戻ってきたパケットを対応する内部ホストへ転送する。
```

## 4. 学びと考察 (Learning & Insights)

- NAT tableでIPアドレスやポート番号の対応関係を管理することで、外部から戻ってきたパケットを適切な内部ホストへ転送できることを理解した。
- ポートフォワーディングを設定することで、通常は外部から直接アクセスできない内部ホストに対して、特定のインバウンド通信を転送できることを理解した。
