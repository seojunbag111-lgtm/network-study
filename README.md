# network-study

ネットワークの基礎から、Linux環境でのネットワーク情報や実際の通信の確認までを学習するためのリポジトリです。

## 目的

ネットワークの仕組みを理解するだけではなく、Linuxのコマンドやパケットキャプチャを使用して、実際の通信状態を確認できるようになることを目的としています。

## 学習内容

- Ethernet、MACアドレス、IPアドレスなどのネットワークの基礎
- ルーティングとネットワーク間通信の仕組み
- TCP / UDPとポート、ソケット
- DNSによる名前解決
- HTTP通信とWebの基本
- Proxy、NAT、Load Balancing
- VPNとネットワークセキュリティ
- Linux環境でのネットワーク情報の確認
- tcpdumpを使用したパケットキャプチャ
